# 3. STATUS DEFINITIONS

- Requirement identified but work has not started.

IN_PROGRESS
- Work is actively being developed.

- Work has been written and is awaiting review.

TESTING
- Work is being validated through tests or verification.

- Required work has been completed, reviewed, verified and committed.

- Progress cannot continue until a defined dependency or issue is resolved.

- Previously accepted work has been intentionally replaced or retired.
