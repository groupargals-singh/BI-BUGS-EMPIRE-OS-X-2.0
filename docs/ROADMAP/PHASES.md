# Delivery Phases

**Status:** Draft phase map; no phase is declared implemented by this document.

Canonical strategy: `../MASTER_SPECIFICATION/30_ROADMAP_20_YEARS.md`; progress evidence: `../MASTER_SPECIFICATION/99_PROJECT_PROGRESS.md`.

- **Phase A — Baseline:** repository inventory, working-tree audit, canonical documents, traceability.
- **Phase B — BI-BUGS website design review:** website sitemap, approved pest-control content, customer enquiry requirements, staff follow-up, interfaces, data ownership, threat model, and acceptance criteria.
- **Phase C — Website vertical slice:** one complete visitor-to-enquiry-to-authorized-staff-review journey through UI/API/data with permission checks and audit evidence.
- **Phase D — Quality hardening:** regression, security, accessibility, recovery, performance, and compatibility checks.
- **Phase E — Release readiness:** reproducible artifact, approvals, monitoring, rollback and support plan.

Exit each phase only on evidence-backed criteria; planned work is not a pass.
