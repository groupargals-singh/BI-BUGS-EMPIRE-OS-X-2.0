# BI-BUGS website frontend — first-build foundation

This is a dependency-free, mobile-first static frontend foundation for the new BI-BUGS Pest Control Services Pvt Ltd website.

## Run locally

From the repository root:

```bash
python -m http.server 8080 --directory frontend
```

Open `http://127.0.0.1:8080` on the development device/browser.

## Current scope

- Responsive landing-page shell and semantic navigation.
- Mobile navigation with keyboard-accessible button state.
- Company name only; no unverified service claims or contact information.
- Explicit placeholders for company profile, service catalogue, and contact/customer journey.

## Not approved / not implemented yet

- Public launch, domain, DNS, hosting, or deployment.
- Official logo, colours, photography, service descriptions, treatment/safety claims, pricing, testimonials, certificates, or coverage areas.
- Enquiry form, appointment booking, customer accounts, online payment, WhatsApp/call links, analytics, or data collection.
- Backend/API/database and staff administration.

Do not replace placeholders with guessed business information. Add customer actions only after owner approval of the journey, data fields, privacy/consent, and handling workflow.
